## Ground-mode negotiation context

What ground carriers actually haggle over — use these as levers, always downward:

- **Tolls and fuel**: the classic excuses to inflate ("es que los peajes", "el ACPM está caro"). A serious rate already includes them; ask for the all-in price from the first number: "¿ese precio es full, con peajes incluido?".
- **Backhaul / return trip**: if the carrier has a return leg on that route, their real cost drops. Probe: "¿tienes carga de regreso por esa ruta?" — if yes, push the price down.
- **Truck type**: an oversized vehicle for the cargo inflates the price. If the cargo fits a smaller truck (turbo instead of tractomula), ask for the rate on the right-sized vehicle.
- **Schedule flexibility**: if the mandate date allows a day of slack, offer it in exchange for a better rate — the date you register in `quoted_date` must still satisfy the mandate.
- **Common surcharges to reject as later additions**: cargue/descargue, standby (tiempo de espera), escolta, seguro. If it wasn't in the first all-in number, it doesn't get added afterwards (anti-ratchet).
